# BuildWise Material Calculator

A lightweight, single-page construction material calculator that runs entirely in the browser. It calculates estimates for concrete, brick walls, plaster, and asphalt roads using metric inputs.

## Use

Open `index.html` in a modern browser. No server, account, or network connection is required.

The calculator saves the five most recent estimates locally in the browser. They can be removed using **Clear history**.

## Important

The figures are planning estimates. Confirm the structural design, local material specifications, and required waste allowance with a qualified engineer before purchasing materials.
